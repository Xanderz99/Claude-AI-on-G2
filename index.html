iPhone Shortcut

Your Shortcut sends questions to this URL (keep it private: anyone with it can send questions to your glasses):

  1. Open Shortcuts, tap +, and name the new shortcut Ask Claude.
  2. Add Dictate Text (or Ask for Input if you'd rather type).
  3. Add Get Contents of URL. Set the URL to the address above and tap Show More. Set Method to POST and Request Body to File, then choose the Dictated Text variable.
  4. Optional: add a header named Title with value new to start a fresh conversation each time, or show to put text on the glasses without asking Claude.
  5. Keep this app open on your glasses, then say "Hey Siri, Ask Claude". You can also add the shortcut to the Action Button or Back Tap.
