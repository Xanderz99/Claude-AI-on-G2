Claude for G2

Glasses: connecting Shortcut inbox: connecting

Uses the Claude app on your iPhone through Shortcuts. You don't need an API key; answers come from your own Claude account.

On your glasses

Set up the iPhone Shortcut

You need the Claude app from the App Store, signed in, and iOS 18 or later. Your private address:

  1. Open Shortcuts, tap +, and name the shortcut Ask Claude on G2.
  2. Add Dictate Text (or Ask for Input if you'd rather type).
  3. Optional, shows your question while Claude thinks: add Get Contents of URL with the address above. Tap Show More, set Method to POST, add a header Title = question, and set Request Body to File → Dictated Text.
  4. Add the Claude app's Ask Claude action. For the prompt, use Dictated Text. You can add "Answer briefly in plain text." to get answers that suit the small display.
  5. Add another Get Contents of URL with the same address, Method POST, and Request Body File → the Response from Ask Claude. No header is needed.
  6. Keep this app open on your glasses and say "Hey Siri, Ask Claude on G2". You can also put the shortcut on the Action Button or Back Tap.

Keep the address private: anyone who has it can put text on your glasses. To show other text, POST it to the same address. Use the header Title = clear to clear the display.
