Claude for G2

Glasses: connecting Shortcut inbox: connecting

Uses the Claude app on your iPhone through Shortcuts. You don't need an API key; answers come from your own Claude account.

On your glasses

Your private address

Both Shortcuts below send text to this address. You need the Claude app from the App Store, signed in, on iOS 18 or later.

Keep it private: anyone who has it can put text on your glasses. Any Shortcut can POST text here. Use the header Title = question for a question or clear to clear the display.

Talk from the glasses, like Even AI

Press and hold the temple and ask your question, then let go. You can also double-tap to start and tap (or just pause) to finish. The glasses show a live sound meter while listening and then "Thinking...". Your iPhone runs the Shortcut , which transcribes your voice, asks Claude, and sends the answer back to the glasses.

  1. In Shortcuts, make a new shortcut named exactly .
  2. Add Get Contents of URL and set the URL to Shortcut Input. This downloads your recording.
  3. Add Transcribe Audio with Contents of URL as its input.
  4. Add Get Contents of URL: the address above, Method POST, header Title = question, Request Body File → Transcription.
  5. Add the Claude app's Ask Claude action with Transcription as the prompt. You can add "Answer briefly in plain text."
  6. Add Get Contents of URL: the address above, Method POST, Request Body File → Response.
  7. Optional: add Open App → Even at the end so you land back in the Even app.

iOS only lets an app open a Shortcut while the app is on screen. Your iPhone has to be unlocked with the Even app open. If the Shortcut doesn't start, tap Run Shortcut above. Recordings are uploaded to your private topic on ntfy and deleted automatically after a few hours.

Ask with Siri (iPhone mic)

  1. Make a shortcut named Ask Claude on G2.
  2. Add Dictate Text (or Ask for Input if you'd rather type).
  3. Optional: add Get Contents of URL: the address above, Method POST, header Title = question, Request Body File → Dictated Text.
  4. Add Ask Claude with Dictated Text as the prompt.
  5. Add Get Contents of URL: the address above, Method POST, Request Body File → Response.
  6. Say "Hey Siri, Ask Claude on G2". This works with your iPhone locked or in your pocket.
